- (claim) ref=r1-eth-1 status=verified class=evidence pub=2026-02 — Controlled benchmark (300 SWE-bench Lite + 138 CTXbench, 4 agent/model pairs) finds repository context files do not generally improve task success; LLM-generated files -0.5%/-2% (n.s.) at +20%/+23% inference cost; developer-written +2.4% (p=0.21).
- (claim) ref=r1-eth-2 status=verified class=evidence pub=2026-02 — Agents do follow context files (uv used 1.6x vs <0.01x; repo tools 2.5x vs <0.05x); cost increases come from extra tests, reads, and reasoning tokens, not disobedience.
- (claim) ref=r1-eth-3 status=verified class=evidence pub=2026-02 — The viral claim that AGENTS.md 'reduces success' is an overread of v1; v3 reports non-significant deltas and neutral wording. Cite the revision.
- (claim) ref=r1-eth-4 status=verified class=evidence pub=2026-05 — 1650-session factorial study finds no detectable adherence effect from file size, instruction position, file architecture, or adjacent-file contradictions across 24-2003 words; within-session decay ~5.6% lower odds per extra generated function.
- (claim) ref=r1-vercel status=unverified class=evidence pub=2026-01 — Vercel vendor eval: 8KB static docs index in AGENTS.md lifted post-cutoff Next.js API task pass rate 53% to 100%; skill-only 53%; n undisclosed, so effect size indicative only.
- (claim) ref=r1-corpus status=verified class=evidence pub=2026-08 — 2303 instruction files from 1925 repos: median 335-535 words; 67% of Claude files edited in multiple commits; median +57 words added vs <15 deleted per commit; testing 75.9%, implementation 70.8%, architecture 68.1%, security 14.8%.
- (claim) ref=r1-spec status=unverified class=standard pub=2026-10 — AGENTS.md remains an unversioned living convention under AAIF; no primary evidence of a v1.1 or frontmatter spec revision; 60k+ projects adoption claimed Dec 2025.
- (claim) ref=r1-codex status=verified class=compatibility pub=2026-10 — Codex loads global + one AGENTS.md per directory root-to-cwd, concatenated, closer file later; default 32 KiB combined cap; chain resolved once per run.
- (claim) ref=r1-claude status=verified class=compatibility pub=2026-10 — Claude Code loads CLAUDE.md ancestors at launch and subdirectory files lazily; AGENTS.md is read only when no CLAUDE.md exists in cwd or above; ~200-line target, 4 MiB hard skip; @AGENTS.md import preferred over a symlink where symlinks need elevated privileges.
- (claim) ref=r1-opencode status=unverified class=compatibility pub=2026-10 — OpenCode walks up from cwd for AGENTS.md/CLAUDE.md, first match per category wins, and does not auto-parse @file references (instructions config combines globs). Ancestor merge vs nearest-only unresolved.
