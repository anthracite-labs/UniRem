# Digest — loading mechanics (round 1, assistant 1)

Lane: B. Loading mechanics. Budget used: ~12 sources / ~20 calls. Accessed 2026-10-23.

## Findings

13. **OpenAI Codex: global file, then one file per directory from project root down to the launch directory, concatenated; 32 KiB cap; resolved once per run.** — source: https://learn.chatgpt.com/docs/agent-configuration/agents-md | publisher: OpenAI | published: unknown | accessed: 2026-10-23 | confidence: high | class: compatibility
   - Order per directory: `AGENTS.override.md` → `AGENTS.md` → `project_doc_fallback_filenames`; "Codex includes at most one file per directory"; "concatenates files from the root down, joining them with blank lines"; "Files closer to your current directory override earlier guidance because they appear later in the combined prompt"; chain built "once per run". `project_doc_max_bytes` = 32768; `CODEX_HOME` relocates the global dir. Implementation comments confirm it does "not walk past the project root" and only covers root→cwd, so a session launched at repo root never loads a nested file mid-session — use `--cd`/`-C` to launch inside the module.

14. **Claude Code: ancestor `CLAUDE.md`/`CLAUDE.local.md` concatenated at launch; subdirectory files load lazily on first read/edit there; `AGENTS.md` is a fallback, not additive, by default (v2.1.277+).** — source: https://docs.claude.com/en/docs/claude-code/memory | publisher: Anthropic | published: unknown | accessed: 2026-10-23 | confidence: high | class: compatibility
   - Loads cwd plus "every directory above it", ordered root→cwd; subdirectory files load "once Claude reads, writes, or edits another file in that subdirectory". `AGENTS.md` and `.claude/AGENTS.md` are read at session start only when no `CLAUDE.md`/`.claude/CLAUDE.md`/`CLAUDE.local.md` exists in cwd or above; `AGENTS.local.md`, `AGENTS.override.md` and `.agents/` are explicitly "Not read". `@path` imports resolve relative to the importing file, max 4 hops, external imports need one-time approval; `claudeMdExcludes` globs files out; setting **Project instructions** = `claude-md-and-agents-md` loads both; files >4 MiB are skipped.

15. **OpenCode: project `AGENTS.md` found by walking up from cwd, plus a global file; one local file wins per category, and includes are config-driven, not `@`-parsed.** — source: https://opencode.ai/docs/rules/ | publisher: OpenCode (Anomaly) | published: 2026-10-22 (page update) | accessed: 2026-10-23 | confidence: medium | class: compatibility
   - "Local files by traversing up from the current directory (`AGENTS.md`, `CLAUDE.md`)"; "The first matching file wins in each category. For example, if you have both `AGENTS.md` and `CLAUDE.md`, only `AGENTS.md` is used"; global `~/.config/opencode/AGENTS.md` beats `~/.claude/CLAUDE.md`; Claude compatibility disabled via `OPENCODE_DISABLE_CLAUDE_CODE*`. `opencode.json` `instructions: []` (globs, remote URLs, 5 s timeout) is "combined with your AGENTS.md files". "opencode doesn't automatically parse file references in AGENTS.md" — `@path` works only if the prompt tells the model to read it. Ambiguity: the doc does not say whether multiple ancestor files merge or only the nearest is read.

16. **GitHub Copilot is surface-dependent: cloud agent/code review use "nearest AGENTS.md wins"; VS Code needs settings and treats nested files as experimental; Copilot CLI merges with no general precedence order.** — source: https://docs.github.com/en/copilot/how-tos/configure-custom-instructions/add-repository-instructions | publisher: GitHub | published: unknown | accessed: 2026-10-23 | confidence: high | class: compatibility
   - Repo docs: `AGENTS.md` "stored anywhere within the repository… the nearest `AGENTS.md` file in the directory tree will take precedence", or a single root `CLAUDE.md`/`GEMINI.md`. VS Code: `chat.useAgentsMdFile` (on by default) attaches root `AGENTS.md`; nested requires `chat.useNestedAgentsMdFiles` and is "experimental". Copilot CLI: standard locations = repo root, cwd, dirs between them, and "any directories nested in the path of a file it is working on"; it "does not define a general precedence order"; `@relative/path` includes work in `AGENTS.md`/`CLAUDE.md` but "Absolute paths and paths beginning with `~/` are not loaded"; edits need a new/resumed session. Per-surface support table: https://docs.github.com/en/copilot/reference/custom-instructions-support.

17. **Cursor: root and nested `AGENTS.md` are supported, with nested content combined and more specific instructions taking precedence.** — source: https://cursor.com/docs/context/rules | publisher: Cursor | published: unknown | accessed: 2026-10-23 | confidence: high | class: compatibility
   - "Cursor supports AGENTS.md in the project root and subdirectories"; "Instructions from nested AGENTS.md files are combined with parent directories, with more specific instructions taking precedence." It is positioned as "a simple alternative to `.cursor/rules`" — plain Markdown, no frontmatter; a plain `.md` inside `.cursor/rules` "is ignored"; `.mdc` rule precedence is Team → Project → User; `@file` mentions are not inlined (the agent reads them on demand); rules are "included at the start of the model context"; guidance is "Keep rules under 500 lines".

18. **Gemini CLI: `GEMINI.md` is the default; `AGENTS.md` loads only if you add it to `context.fileName`; discovery is global + cwd/ancestors + a 200-directory subdirectory sweep + JIT scan.** — source: https://geminicli.com/docs/reference/configuration/ | publisher: Google (Gemini CLI) | published: 2026-10-15 | accessed: 2026-10-23 | confidence: high | class: compatibility
   - Hierarchy: `~/.gemini/GEMINI.md`, then the configured filename in cwd and each parent up to `.git` or home, then subdirectories (default `context.discoveryMaxDirs` 200), plus "when a tool accesses a file or directory, the CLI automatically scans … that directory and its ancestors up to a trusted root". All matches are concatenated with path separators into the system prompt; `@path` imports supported; `/memory show` / `/memory reload`; boundary via `context.memoryBoundaryMarkers` (default `[".git"]`). Configure with `"context": {"fileName": ["AGENTS.md","GEMINI.md"]}`; filename in `GEMINI.md` docs: https://github.com/google-gemini/gemini-cli/blob/main/docs/cli/gemini-md.md.

19. **Cost is per-harness and sometimes truncated silently: Codex hard-stops at 32 KiB, Claude skips >4 MiB and warns past ~200 lines, Cursor recommends <500 lines, Windsurf caps rule files at 12,000 chars.** — source: https://learn.chatgpt.com/docs/agent-configuration/agents-md | publisher: OpenAI | published: unknown | accessed: 2026-10-23 | confidence: high | class: compatibility
   - Codex "stops adding files once the combined size reaches the limit" — deeper modules silently vanish once the budget is spent. Claude warns at startup/`/status` when a file or the combined set exceeds recommended length; Windsurf/Devin Desktop: workspace rules 12,000 chars each, global 6,000, root `AGENTS.md` always-on, subdirectory `AGENTS.md` auto-globbed (https://docs.windsurf.com/windsurf/cascade/memories, current docs now branded Devin Desktop; confidence medium).

## Contradictions

- **Nearest-file-wins vs concatenate-everything** — see standard-adoption digest; unresolved in the standard tracker (https://github.com/agentsmd/agents.md/issues/53).
- **Copilot precedence** — repo docs say nearest wins; VS Code and CLI docs say additive with no general order.
- **"Supported" vs "loaded by default" for Gemini CLI** — adoption list vs `context.fileName` configuration.
