UniRem · Color Theme Variations

Six palette directions for a dark-mode-first Android remote for Samsung Tizen TVs. Dark (primary) and light (secondary, simplified) shown side by side. Every panel carries the full semantic token set as labeled hex chips plus a mini-remote snippet in real strings.

Ambient state ring family — the app's signature honesty element, shown as the five rings under each remote: idle → submitted (soft pulse) → observed (settled) · unconfirmed (TV state unknown) · offline (TV unreachable). The D-pad center key wears the ring in its observed color.
